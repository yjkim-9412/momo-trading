# 주문 리스트 조회

**Method:** GET
**URL:** `https://api.bithumb.com/v1/orders`
**인증:** Bearer JWT 토큰

## 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| Authorization | Header | Yes | JWT Bearer token |
| market | Query | No | Trading pair symbol (e.g., KRW-BTC) |
| state | Query | No | Order status: wait, watch, done, cancel |
| states | Query | No | Multiple statuses (cannot mix watch with others) |
| uuids | Query | No | Order IDs (max 30) |
| client_order_ids | Query | No | User-specified order IDs (max 30) |
| page | Query | No | Page number (default: 1) |
| limit | Query | No | Results per page (default: 100) |
| order_by | Query | No | Sort: asc or desc (default: desc) |

## 응답

| 필드 | 타입 | 설명 |
|------|------|------|
| uuid | string | Order unique ID |
| client_order_id | string | User-specified ID |
| side | string | "bid" or "ask" |
| ord_type | string | "limit", "price", or "market" |
| price | string | Order price |
| state | string | Current order status |
| market | string | Trading pair symbol |
| created_at | string | Creation timestamp (ISO 8601) |
| volume | string | Ordered quantity |
| remaining_volume | string | Unfilled quantity |
| reserved_fee | string | Reserved fee amount |
| remaining_fee | string | Outstanding fee |
| paid_fee | string | Used fee |
| locked | string | Amount in trade |
| executed_volume | string | Filled quantity |
| trades_count | integer | Number of executions |

## 코드 예제

### Python
```python
import jwt
import uuid
import hashlib
import time
from urllib.parse import urlencode
import requests

accessKey = 'YOUR_API_KEY'
secretKey = 'YOUR_SECRET_KEY'
apiUrl = 'https://api.bithumb.com'

param = dict(market='KRW-BTC', state='done', limit=50)
query = urlencode(param).encode()
hash = hashlib.sha512()
hash.update(query)
query_hash = hash.hexdigest()
payload = {
    'access_key': accessKey,
    'nonce': str(uuid.uuid4()),
    'timestamp': round(time.time() * 1000),
    'query_hash': query_hash,
    'query_hash_alg': 'SHA512',
}
jwt_token = jwt.encode(payload, secretKey)
headers = {
    'Authorization': f'Bearer {jwt_token}'
}

response = requests.get(apiUrl + '/v1/orders',
                      params=param, headers=headers)
print(response.json())
```

### JavaScript
```javascript
const jwt = require('jsonwebtoken');
const { v4: uuidv4 } = require('uuid');
const crypto = require('crypto');
const axios = require('axios')

const accessKey = 'YOUR_API_KEY'
const secretKey = 'YOUR_SECRET_KEY'
const apiUrl = 'https://api.bithumb.com'

const query = 'market=KRW-BTC&state=done&limit=50'
const alg = 'SHA512'
const hash = crypto.createHash(alg)
const queryHash = hash.update(query, 'utf-8').digest('hex')
const payload = {
  access_key: accessKey,
  nonce: uuidv4(),
  timestamp: Date.now(),
  query_hash: queryHash,
  query_hash_alg: alg
}
const jwtToken = jwt.sign(payload, secretKey)
const config = {
  headers: {
    Authorization: `Bearer ${jwtToken}`
  }
}

axios.get(apiUrl + '/v1/orders?' + query, config)
  .then((response) => {
    console.log('data: ', response.data)
  })
  .catch((error) => {
    console.log(error.response.data)
  })
```

### Java
```java
import com.auth0.jwt.JWT;
import com.auth0.jwt.algorithms.Algorithm;
import org.apache.http.client.methods.HttpGet;
import org.apache.http.impl.client.CloseableHttpClient;
import org.apache.http.impl.client.HttpClients;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.math.BigInteger;
import java.util.UUID;

String accessKey = "YOUR_API_KEY";
String secretKey = "YOUR_SECRET_KEY";
String apiUrl = "https://api.bithumb.com";

String query = "market=KRW-BTC&state=done&limit=50";

MessageDigest md = MessageDigest.getInstance("SHA-512");
md.update(query.getBytes(StandardCharsets.UTF_8));
String queryHash = String.format("%0128x", new BigInteger(1, md.digest()));

Algorithm algorithm = Algorithm.HMAC256(secretKey);
String jwtToken = JWT.create()
  .withClaim("access_key", accessKey)
  .withClaim("nonce", UUID.randomUUID().toString())
  .withClaim("timestamp", System.currentTimeMillis())
  .withClaim("query_hash", queryHash)
  .withClaim("query_hash_alg", "SHA512")
  .sign(algorithm);

HttpGet httpRequest = new HttpGet(apiUrl + "/v1/orders?" + query);
httpRequest.addHeader("Authorization", "Bearer " + jwtToken);
```

## 인증

JWT Token Generation:
- Required Claims: access_key, nonce, timestamp, query_hash, query_hash_alg
- Hash Algorithm: SHA-512 (for query string)
- Token Format: `Bearer {jwtToken}`

## 주의사항

- Maximum 30 orders per request for uuid/client_order_ids parameters
- Cannot combine "watch" state with other general order states
- When both uuids and client_order_ids provided, uuids takes precedence
- Default sorts by creation descending
