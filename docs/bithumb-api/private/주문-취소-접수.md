# 주문 취소 접수

**Method:** DELETE
**URL:** `https://api.bithumb.com/v1/order`
**인증:** Bearer JWT 토큰

## 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| Authorization | Header | Yes | JWT Bearer token |
| uuid | Query | Yes | Order's unique ID |

## 응답

| 필드 | 타입 | 설명 |
|------|------|------|
| uuid | string | Order unique ID |
| client_order_id | string | User-specified ID |
| side | string | "ask" or "bid" |
| ord_type | string | "limit", "price", or "market" |
| price | string | Order price |
| state | string | "wait", "watch", "done", or "cancel" |
| market | string | Trading pair symbol |
| created_at | string | ISO 8601 timestamp |
| volume | string | Ordered quantity |
| remaining_volume | string | Unfilled quantity |
| reserved_fee | string | Reserved fee amount |
| remaining_fee | string | Remaining fee |
| paid_fee | string | Used fee |
| locked | string | Amount in trade |
| executed_volume | string | Filled quantity |
| trades_count | integer | Number of executions |

## 코드 예제

### Python
```python
import jwt
import uuid
import hashlib
import time
import requests

accessKey = 'YOUR_API_KEY'
secretKey = 'YOUR_SECRET_KEY'
apiUrl = 'https://api.bithumb.com'

param = dict(uuid='C0917000000000070001')
query = '&'.join([f'{k}={v}' for k, v in param.items()])

hash_obj = hashlib.sha512()
hash_obj.update(query.encode('utf-8'))
query_hash = hash_obj.hexdigest()

payload = {
  'access_key': accessKey,
  'nonce': str(uuid.uuid4()),
  'timestamp': round(time.time() * 1000),
  'query_hash': query_hash,
  'query_hash_alg': 'SHA512'
}

jwt_token = jwt.encode(payload, secretKey)
headers = {'Authorization': f'Bearer {jwt_token}'}

response = requests.delete(apiUrl + '/v1/order', params=param, headers=headers)
print(response.json())
```

### JavaScript
```javascript
const jwt = require('jsonwebtoken');
const { v4: uuidv4 } = require('uuid');
const crypto = require('crypto');
const axios = require('axios');

const accessKey = 'YOUR_API_KEY';
const secretKey = 'YOUR_SECRET_KEY';
const apiUrl = 'https://api.bithumb.com';

const query = 'uuid=C0917000000000070001';
const hash = crypto.createHash('SHA512')
  .update(query, 'utf-8').digest('hex');
const payload = {
  access_key: accessKey,
  nonce: uuidv4(),
  timestamp: Date.now(),
  query_hash: hash,
  query_hash_alg: 'SHA512'
};
const token = jwt.sign(payload, secretKey);
axios.delete(apiUrl + '/v1/order?' + query, {
  headers: { Authorization: `Bearer ${token}` }
});
```

### Java
```java
import com.auth0.jwt.JWT;
import com.auth0.jwt.algorithms.Algorithm;
import org.apache.http.client.methods.HttpDelete;
import org.apache.http.impl.client.CloseableHttpClient;
import org.apache.http.impl.client.HttpClients;
import java.nio.charset.StandardCharsets;
import java.security.MessageDigest;
import java.math.BigInteger;
import java.util.UUID;

String accessKey = "YOUR_API_KEY";
String secretKey = "YOUR_SECRET_KEY";
String apiUrl = "https://api.bithumb.com";

String query = "uuid=C0917000000000070001";
MessageDigest md = MessageDigest.getInstance("SHA-512");
String queryHash = String.format("%0128x",
  new BigInteger(1, md.digest(query.getBytes())));
String jwtToken = JWT.create()
  .withClaim("access_key", accessKey)
  .withClaim("query_hash", queryHash)
  .withClaim("query_hash_alg", "SHA512")
  .sign(Algorithm.HMAC256(secretKey));
HttpDelete req = new HttpDelete(apiUrl + "/v1/order?" + query);
req.addHeader("Authorization", "Bearer " + jwtToken);
```

## 인증

JWT Token Generation:
- Required Claims: access_key, nonce, timestamp, query_hash, query_hash_alg
- Hash Algorithm: SHA-512 (for query string)
- Sign with HMAC256 using secret key

## 주의사항

- Returns cancelled order details with updated state
- Requires valid JWT authentication with query hash validation
- Only orders matching the provided UUID can be cancelled
