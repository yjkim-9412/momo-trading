# 디지털-자산-출금하기

**Method:** POST
**URL:** `https://api.bithumb.com/v1/withdraws/coin`
**인증:** Bearer JWT 토큰

## 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| Authorization | header | 필수 | Bearer JWT 토큰 |

## 요청 본문

요청 본문은 POST 데이터로 전달되며, 정확한 스키마는 코드 예제를 참조하세요.

## 응답

```json
{
  "type": "string",
  "uuid": "string",
  "currency": "string",
  "net_type": null,
  "txid": "string",
  "state": "string",
  "created_at": "string",
  "done_at": "string",
  "amount": "string",
  "fee": "string",
  "transaction_type": null
}
```

| 필드 | 타입 | 설명 |
|------|------|------|
| type | string | 거래 타입 |
| uuid | string | 출금 UUID |
| currency | string | 화폐 코드 |
| net_type | null | 네트워크 타입 |
| txid | string | 거래 ID |
| state | string | 상태 |
| created_at | string | 생성 시간 (ISO 8601) |
| done_at | string | 완료 시간 (ISO 8601) |
| amount | string | 출금액 |
| fee | string | 수수료 |
| transaction_type | null | 거래 분류 |

## 인증

**방식:** JWT (JSON Web Token)

**필수 클레임:**
- `access_key` - API 키
- `nonce` - UUID v4
- `timestamp` - 현재 시간 (밀리초)
- `query_hash` - 쿼리 문자열의 SHA512 해시
- `query_hash_alg` - "SHA512"

## 코드 예제

### Python
```python
import jwt
import uuid
import hashlib
import time
import requests

accessKey = 'YOUR_API_KEY'
secretKey = 'YOUR_SECRET_KEY'
apiUrl = 'https://api.bithumb.com'

query = 'currency=XRP&limit=100'
hash_obj = hashlib.sha512()
hash_obj.update(query.encode())
query_hash = hash_obj.hexdigest()

payload = {
  'access_key': accessKey,
  'nonce': str(uuid.uuid4()),
  'timestamp': round(time.time() * 1000),
  'query_hash': query_hash,
  'query_hash_alg': 'SHA512'
}

jwt_token = jwt.encode(payload, secretKey)
headers = {'Authorization': f'Bearer {jwt_token}'}

response = requests.post(apiUrl + '/v1/withdraws/coin', headers=headers)
print(response.json())
```

### JavaScript
```javascript
const jwt = require('jsonwebtoken');
const { v4: uuidv4 } = require('uuid');
const crypto = require('crypto');
const axios = require('axios');

const accessKey = 'YOUR_API_KEY';
const secretKey = 'YOUR_SECRET_KEY';
const query = 'currency=XRP&limit=100&page=1&order_by=desc';
const alg = 'SHA512';
const hash = crypto.createHash(alg);
const queryHash = hash.update(query, 'utf-8').digest('hex');

const payload = {
  access_key: accessKey,
  nonce: uuidv4(),
  timestamp: Date.now(),
  query_hash: queryHash,
  query_hash_alg: alg
};

const jwtToken = jwt.sign(payload, secretKey);
const config = {
  headers: { Authorization: `Bearer ${jwtToken}` }
};

axios.post('https://api.bithumb.com/v1/withdraws/coin', {}, config)
  .then(response => console.log(response.data))
  .catch(error => console.error(error.response.data));
```

### Java
```java
import com.auth0.jwt.JWT;
import com.auth0.jwt.algorithms.Algorithm;
import java.security.MessageDigest;
import java.math.BigInteger;
import java.util.UUID;

String accessKey = "YOUR_API_KEY";
String secretKey = "YOUR_SECRET_KEY";
String query = "currency=XRP&limit=100";

MessageDigest md = MessageDigest.getInstance("SHA-512");
md.update(query.getBytes());
String queryHash = String.format("%0128x", new BigInteger(1, md.digest()));

Algorithm algorithm = Algorithm.HMAC256(secretKey);
String jwtToken = JWT.create()
  .withClaim("access_key", accessKey)
  .withClaim("nonce", UUID.randomUUID().toString())
  .withClaim("timestamp", System.currentTimeMillis())
  .withClaim("query_hash", queryHash)
  .withClaim("query_hash_alg", "SHA512")
  .sign(algorithm);
```
