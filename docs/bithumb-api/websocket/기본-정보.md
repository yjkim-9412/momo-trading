# WebSocket 기본 정보

**Protocol:** WebSocket (RFC 6455)
**인증:** Public 불필요 / Private JWT Bearer

## 엔드포인트

| 채널 | URL | 인증 |
|------|-----|------|
| Public | `wss://ws-api.bithumb.com/websocket/v1` | 불필요 |
| Private | `wss://ws-api.bithumb.com/websocket/v1/private` | JWT Bearer |

## 연결 제한

| 항목 | 제한 |
|------|------|
| 연결 요청 | 10회/초/IP |
| 메시지 전송 | 5회/초, 100회/분 (per connection) |
| 데이터 수신 | 제한 없음 |
| Idle Timeout | ~120초 (송수신 없으면 서버 측 연결 해제) |

## 연결 유지 (Heartbeat)

- 활성 연결에 서버가 `{"status":"UP"}` 메시지를 매 10초 전송
- 클라이언트는 RFC 6455 5.5.2 PING 프레임을 전송하여 연결 유지
- ~120초간 송수신 없으면 서버가 연결 해제

## 인증 (Private 채널)

WebSocket 핸드셰이크 시 `Authorization` 헤더에 JWT Bearer 토큰을 포함한다.

**JWT Payload:**

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| access_key | String | O | API Key |
| nonce | String | O | UUID v4 (요청마다 고유) |
| timestamp | Long | O | 현재 시각 (밀리초) |

서명: **HS256** (Secret Key)

```javascript
const payload = {
  access_key: accessKey,
  nonce: uuidv4(),
  timestamp: Date.now()
};
const jwtToken = jwt.sign(payload, secretKey);
const ws = new WebSocket("wss://ws-api.bithumb.com/websocket/v1/private", {
  headers: { authorization: `Bearer ${jwtToken}` }
});
```

```python
import jwt, uuid, time, websockets

payload = {
    "access_key": access_key,
    "nonce": str(uuid.uuid4()),
    "timestamp": int(time.time() * 1000),
}
jwt_token = jwt.encode(payload, secret_key, algorithm="HS256")
async with websockets.connect(
    "wss://ws-api.bithumb.com/websocket/v1/private",
    additional_headers={"Authorization": f"Bearer {jwt_token}"}
) as ws:
    ...
```

## 요청 형식

JSON 배열로 전송: `[{ticket}, {type}, ..., {type}, {format}]`

| 세그먼트 | 필수 | 필드 | 설명 |
|----------|------|------|------|
| ticket | O | `ticket`: String | 고유 식별자 (UUID 권장) |
| type | O | `type`: String | 구독 유형 (`ticker`, `trade`, `orderbook`, `myOrder`, `myAsset`) |
| | | `codes`: List | 마켓 코드 목록 (대문자, 예: `["KRW-BTC"]`) |
| | | `isOnlySnapshot`: Boolean | 스냅샷만 수신 (기본: false) |
| | | `isOnlyRealtime`: Boolean | 실시간만 수신 (기본: false) |
| format | N | `format`: String | `"DEFAULT"` (전체 필드명) 또는 `"SIMPLE"` (축약 필드명). 기본: DEFAULT |

### 요청 예시

```json
[
  {"ticket": "unique-ticket-id"},
  {"type": "ticker", "codes": ["KRW-BTC", "KRW-ETH"]},
  {"type": "trade", "codes": ["KRW-BTC"], "isOnlyRealtime": true},
  {"format": "DEFAULT"}
]
```

### 여러 type 동시 구독

하나의 연결에서 여러 `type` 세그먼트를 포함하여 동시 구독 가능:

```json
[
  {"ticket": "my-ticket"},
  {"type": "ticker", "codes": ["KRW-BTC"]},
  {"type": "orderbook", "codes": ["KRW-BTC"], "level": 10},
  {"type": "trade", "codes": ["KRW-ETH"]},
  {"format": "SIMPLE"}
]
```

## 구독 유형

| type | 채널 | 설명 | codes 필수 |
|------|------|------|-----------|
| `ticker` | Public | 현재가 실시간 정보 (32개 필드) | O |
| `trade` | Public | 체결 내역 (14개 필드) | O |
| `orderbook` | Public | 호가 정보 + depth aggregation | O |
| `myOrder` | Private | 내 주문 상태 변경 (20개 필드) | N (빈 배열 = 전체) |
| `myAsset` | Private | 내 자산 변동 | N (codes 없음) |

## 에러 코드

| error.name | error.message |
|------------|---------------|
| `WRONG_FORMAT` | Format 이 맞지 않습니다 |
| `NO_TICKET` | 티켓이 존재하지 않거나, 유효하지 않습니다 |
| `NO_TYPE` | type 필드가 존재하지 않습니다 |
| `NO_CODES` | codes 필드가 존재하지 않습니다 |
| `INVALID_PARAM` | codes 필드가 비어 있습니다 |
| `INVALID_PARAM_FORMAT` | {}은 지원하지 않는 포맷입니다 |

### 에러 응답 예시

```json
{
  "error": {
    "name": "NO_TICKET",
    "message": "티켓이 존재하지 않거나, 유효하지 않습니다."
  }
}
```
