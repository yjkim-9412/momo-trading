# 마켓코드 조회

**Method:** GET
**URL:** `https://api.bithumb.com/v1/market/all`
**인증:** 불필요

## 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| isDetails | boolean | 선택 | 유의종목 필드와 같은 상세 정보 노출 여부 (기본값: false) |

## 응답

| 필드 | 타입 | 설명 |
|------|------|------|
| market | string | 거래쌍 식별자 (예: KRW-BTC) |
| korean_name | string | 한글 자산명 (예: 비트코인) |
| english_name | string | 영문 자산명 (예: Bitcoin) |

응답은 객체 배열 형식입니다.

## 코드 예제

### Python
```python
import requests

url = "https://api.bithumb.com/v1/market/all?isDetails=false"
headers = {"accept": "application/json"}
response = requests.get(url, headers=headers)
print(response.json())
```

### JavaScript
```javascript
const options = {method: 'GET', headers: {accept: 'application/json'}};

fetch('https://api.bithumb.com/v1/market/all?isDetails=false', options)
 .then(response => response.json())
 .then(response => console.log(response))
 .catch(err => console.error(err));
```

### Java
```java
OkHttpClient client = new OkHttpClient();

Request request = new Request.Builder()
 .url("https://api.bithumb.com/v1/market/all?isDetails=false")
 .get()
 .addHeader("accept", "application/json")
 .build();

Response response = client.newCall(request).execute();
```
