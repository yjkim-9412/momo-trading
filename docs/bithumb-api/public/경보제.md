# 경보제

**Method:** GET
**URL:** `https://api.bithumb.com/v1/market/virtual_asset_warning`
**인증:** 불필요

## 파라미터

파라미터 없음. 단순 GET 요청입니다.

## 응답

| 필드 | 타입 | 설명 |
|------|------|------|
| market | string | 거래쌍 심볼 (예: KRW-BTC, KRW-ETH) |
| warning_type | string | 발령된 경보 카테고리 (예: PRICE_SUDDEN_FLUCTUATION) |
| warning_step | string | 경보 심각도 수준 |
| end_date | string | 경보 기간 만료 시각 (예: 2026-01-15 18:00:00) |

응답은 객체 배열 형식입니다.

## 코드 예제

### Python
```python
import requests

url = "https://api.bithumb.com/v1/market/virtual_asset_warning"
headers = {"accept": "application/json"}
response = requests.get(url, headers=headers)
print(response.json())
```

### JavaScript
```javascript
const options = {
  method: 'GET',
  headers: { accept: 'application/json' }
};

fetch('https://api.bithumb.com/v1/market/virtual_asset_warning', options)
  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

### Java
```java
OkHttpClient client = new OkHttpClient();

Request request = new Request.Builder()
  .url("https://api.bithumb.com/v1/market/virtual_asset_warning")
  .get()
  .addHeader("accept", "application/json")
  .build();

Response response = client.newCall(request).execute();
System.out.println(response.body().string());
```

## 설명

- 현재 모니터링 중인 자산의 경보 상태 목록을 반환합니다
- 경보 유형은 급격한 가격 변동, 거래량 변화, 가격 차이 등을 포함합니다
- 심각도 수준은 warning_step 필드에 표시됩니다
