# 호가 정보 조회

**Method:** GET
**URL:** `https://api.bithumb.com/v1/orderbook`
**인증:** 불필요

## 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| markets | 문자열 배열 | 필수 | 마켓 코드 목록 (예: KRW-BTC,BTC-ETH) |

## 응답

| 필드 | 타입 | 설명 |
|------|------|------|
| market | string | 마켓 코드 (예: KRW-BTC) |
| timestamp | integer | 타임스탐프 (예: 1529910247984) |
| total_ask_size | number | 총 매도 호가 규모 (예: 8.83621228) |
| total_bid_size | number | 총 매수 호가 규모 (예: 2.43976741) |

### orderbook_units (호가 정보 배열)

| 필드 | 타입 | 설명 |
|------|------|------|
| ask_price | integer | 매도 호가 (예: 6956000) |
| bid_price | integer | 매수 호가 (예: 6954000) |
| ask_size | number | 매도 호가 규모 (예: 0.24078656) |
| bid_size | number | 매수 호가 규모 (예: 0.00718341) |

응답은 객체 배열 형식입니다.

## 코드 예제

### Python
```python
import requests

url = "https://api.bithumb.com/v1/orderbook?markets=KRW-BTC"
headers = {"accept": "application/json"}
response = requests.get(url, headers=headers)
print(response.json())
```

### JavaScript
```javascript
const options = {method: 'GET', headers: {accept: 'application/json'}};

fetch('https://api.bithumb.com/v1/orderbook?markets=KRW-BTC', options)
  .then(response => response.json())
  .then(response => console.log(response))
  .catch(err => console.error(err));
```

### Java
```java
OkHttpClient client = new OkHttpClient();

Request request = new Request.Builder()
  .url("https://api.bithumb.com/v1/orderbook?markets=KRW-BTC")
  .get()
  .addHeader("accept", "application/json")
  .build();

Response response = client.newCall(request).execute();
```
