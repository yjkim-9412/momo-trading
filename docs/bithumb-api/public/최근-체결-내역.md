# 최근 체결 내역

**Method:** GET
**URL:** `https://api.bithumb.com/v1/trades/ticks`
**인증:** 불필요

## 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| market | string | 필수 | 마켓 코드 (예: KRW-BTC) |
| to | string | 선택 | 마지막 체결 시각 (HHmmss 또는 HH:mm:ss 형식). 비워서 요청 시 가장 최근 데이터 (00:00:00 ~ 23:59:59) |
| count | integer | 선택 | 체결 개수 (1~500). 기본값: 1 |
| cursor | string | 선택 | 페이지네이션 커서 (sequentialId) |
| daysAgo | integer | 선택 | 최근 체결 기준 과거 7일 내 데이터 조회. 비워서 요청 시 최근 체결일 기준 (범위: 1 ~ 7) |

## 응답

| 필드 | 타입 | 설명 |
|------|------|------|
| market | string | 거래쌍 심볼 (예: KRW-BTC) |
| trade_date_utc | string | 체결 날짜 (UTC) (예: 2018-04-18) |
| trade_time_utc | string | 체결 시간 (UTC) (예: 10:19:58) |
| timestamp | integer | Unix 타임스탐프 (밀리초) |
| trade_price | integer | 단위당 가격 |
| trade_volume | number | 체결량 |
| prev_closing_price | integer | 전일 종가 |
| change_price | integer | 가격 변화량 |
| ask_bid | string | 주문 방향 (ASK=매도, BID=매수) |

응답은 객체 배열 형식입니다.

## 코드 예제

### Python
```python
import requests

url = "https://api.bithumb.com/v1/trades/ticks?market=krw-btc&count=1"
headers = {"accept": "application/json"}
response = requests.get(url, headers=headers)
print(response.json())
```

### JavaScript
```javascript
const options = {method: 'GET', headers: {accept: 'application/json'}};

fetch('https://api.bithumb.com/v1/trades/ticks?market=krw-btc&count=1', options)
 .then(response => response.json())
 .then(response => console.log(response))
 .catch(err => console.error(err));
```

### Java
```java
OkHttpClient client = new OkHttpClient();

Request request = new Request.Builder()
 .url("https://api.bithumb.com/v1/trades/ticks?market=krw-btc&count=1")
 .get()
 .addHeader("accept", "application/json")
 .build();

Response response = client.newCall(request).execute();
```

## 설명

- 파라미터를 지정하지 않을 경우 가장 최근 체결 스냅샷을 반환합니다
- `cursor` 파라미터로 페이지네이션을 지원합니다
- 시간 파라미터는 24시간 형식을 사용하며, 빈 값은 현재 시간으로 기본값 설정됩니다
- 요청당 최대 500개의 체결 조회 가능
- `daysAgo` 파라미터로 최대 7일까지의 과거 데이터 조회 가능
