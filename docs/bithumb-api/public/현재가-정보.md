# 현재가 정보

**Method:** GET
**URL:** `https://api.bithumb.com/v1/ticker`
**인증:** 불필요

## 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| markets | string | 필수 | 쉼표로 구분된 마켓 코드 (예: KRW-BTC, BTC-ETH) |

## 응답

| 필드 | 타입 | 설명 |
|------|------|------|
| market | string | 거래쌍 심볼 (예: KRW-BTC) |
| trade_date | string | 거래 날짜 (YYYYMMDD 형식) |
| trade_time | string | 거래 시간 (HHmmss 형식) |
| trade_date_kst | string | KST 거래 날짜 |
| trade_time_kst | string | KST 거래 시간 |
| trade_timestamp | integer | 거래 타임스탐프 (밀리초) |
| opening_price | integer | 시가 |
| high_price | integer | 고가 |
| low_price | integer | 저가 |
| trade_price | integer | 현재 거래가 |
| prev_closing_price | integer | 전일 종가 |
| change | string | 변화 방향 ("RISE", "FALL", "EVEN") |
| change_price | integer | 가격 변화량 |
| change_rate | number | 가격 변화율 |
| signed_change_price | integer | 부호가 있는 변화 가격 |
| signed_change_rate | number | 부호가 있는 변화율 |
| trade_volume | number | 현재 캔들의 거래량 |
| acc_trade_price | number | 누적 거래 대금 |
| acc_trade_price_24h | number | 24시간 누적 거래 대금 |
| acc_trade_volume | number | 누적 거래량 |
| acc_trade_volume_24h | number | 24시간 누적 거래량 |
| highest_52_week_price | integer | 52주 최고가 |
| highest_52_week_date | string | 52주 최고가 날짜 |
| lowest_52_week_price | integer | 52주 최저가 |
| lowest_52_week_date | string | 52주 최저가 날짜 |
| timestamp | integer | 응답 타임스탐프 (밀리초) |

응답은 객체 배열 형식입니다.

## 코드 예제

### Python
```python
import requests

url = "https://api.bithumb.com/v1/ticker?markets=KRW-BTC"
headers = {"accept": "application/json"}
response = requests.get(url, headers=headers)
print(response.json())
```

### JavaScript
```javascript
const options = {method: 'GET', headers: {accept: 'application/json'}};

fetch('https://api.bithumb.com/v1/ticker?markets=KRW-BTC', options)
 .then(response => response.json())
 .then(response => console.log(response))
 .catch(err => console.error(err));
```

### Java
```java
OkHttpClient client = new OkHttpClient();

Request request = new Request.Builder()
 .url("https://api.bithumb.com/v1/ticker?markets=KRW-BTC")
 .get()
 .addHeader("accept", "application/json")
 .build();

Response response = client.newCall(request).execute();
```
