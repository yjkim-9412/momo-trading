# 해외주식 체결기준현재잔고

**URL:** `/uapi/overseas-stock/v1/trading/inquire-present-balance`
**Method:** GET
**API ID:** v1_해외주식-008

## tr_id

| 구분 | tr_id | 비고 |
|------|-------|------|
| 실전 | CTRP6504R | |
| 모의 | VTRP6504R | |

## 파라미터

| 이름 | 타입 | 필수 | 설명 |
|------|------|------|------|
| CANO | string | Yes | 종합계좌번호 (계좌번호 체계 8-2의 앞 8자리) |
| ACNT_PRDT_CD | string | Yes | 계좌상품코드 (계좌번호 체계 8-2의 뒤 2자리) |
| WCRC_FRCR_DVSN_CD | string | Yes | 원화외화구분코드 (01: 원화, 02: 외화) |
| NATN_CD | string | Yes | 국가코드 (아래 참조) |
| TR_MKET_CD | string | Yes | 거래시장코드 (아래 참조) |
| INQR_DVSN_CD | string | Yes | 조회구분코드 (00: 전체, 01: 일반해외주식, 02: 미니스탁) |

## 응답

- `output1`: 보유종목 목록
- `output2`: 계좌 요약
- `output3`: 추가 정보

## 비고

- 체결 기준의 현재 잔고를 조회하는 API
- 연속조회 지원: `tr_cont`가 "M" 또는 "F"이면 다음 페이지 존재
- 국가코드와 거래시장코드의 조합에 주의
